## 🚀 快速集成步骤

### 第一步：复制文件到项目

#### 方法一：使用批处理脚本（推荐）

1. 双击运行 `复制到public.bat`
2. 按提示完成复制

#### 方法二：手动复制

1. 复制 `public/` 下的所有内容到你的Vue项目 `public/` 目录
2. 复制 `Live2DAvatar.vue` 到 `src/components/` 目录

### 第二步：在你的页面中使用

```vue
<template>
  <div class="interview-page">
    <Live2DAvatar
      ref="avatar"
      mode="live2d"
      :speaking="isSpeaking"
      @loaded="onAvatarLoaded"
      @error="onAvatarError"
    />
  </div>
</template>

<script setup>
import { ref } from 'vue'
import Live2DAvatar from './components/Live2DAvatar.vue'

const avatar = ref(null)
const isSpeaking = ref(false)

function onAvatarLoaded() {
  console.log('数字人加载完成！')
}

async function handleAIMessage(text) {
  isSpeaking.value = true

  // 播放TTS
  const audioUrl = await fetchTTS(text)
  avatar.value.speak(audioUrl)

  // 模拟说话结束
  setTimeout(() => {
    isSpeaking.value = false
  }, 3000)
}
</script>
```

## 🎭 组件API

### 属性 (Props)

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `mode` | String | `'live2d'` | 显示模式：`'live2d'` 或 `'css'` |
| `gender` | String | `'female'` | CSS模式下的性别：`'female'` 或 `'male'` |
| `speaking` | Boolean | `false` | 控制是否显示说话动画 |

### 事件 (Events)

| 事件 | 参数 | 说明 |
|------|------|------|
| `loaded` | - | 数字人加载完成 |
| `error` | Error | 加载失败 |

### 方法 (Expose)

| 方法 | 参数 | 说明 |
|------|------|------|
| `speak(audioUrl)` | 音频URL | 让数字人说话（播放音频+动画） |
| `stopSpeaking()` | - | 停止说话 |
| `setExpression(expr)` | 表情名 | 设置表情 |
| `triggerMotion(motion)` | 动作名 | 触发动作 |

### 可用的表情

- `'angry'` - 愤怒
- `'sad'` - 伤心
- `'happy'` - 开心（微笑）
- `'surprised'` - 惊讶
- `'normal'` - 平常

### 可用的动作

- `'idle'` - 待机
- `'handwave'` - 挥手
- `'kime01'` - 鞠躬1
- `'kime02'` - 鞠躬2

## 💡 使用示例

### 完整面试场景

```vue
<template>
  <div class="interview-container">
    <div class="avatar-section">
      <Live2DAvatar
        ref="avatarRef"
        mode="live2d"
        :speaking="isSpeaking"
        @loaded="onLoaded"
      />
    </div>

    <div class="chat-section">
      <div v-for="msg in messages" :key="msg.id" :class="msg.role">
        {{ msg.content }}
      </div>

      <input v-model="userInput" @keyup.enter="sendMessage" />
      <button @click="sendMessage">发送</button>
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue'
import Live2DAvatar from './components/Live2DAvatar.vue'

const avatarRef = ref(null)
const isSpeaking = ref(false)
const userInput = ref('')
const messages = ref([])

function onLoaded() {
  console.log('面试官准备好了')
  // 欢迎语
  setTimeout(() => {
    handleAIMessage('你好，欢迎参加今天的面试，请先做一个自我介绍。')
  }, 1000)
}

async function handleAIMessage(text) {
  isSpeaking.value = true

  messages.value.push({
    id: Date.now(),
    role: 'assistant',
    content: text
  })

  // 获取TTS音频
  const audioUrl = await generateTTS(text)

  // 播放并等待结束
  avatarRef.value.speak(audioUrl)

  setTimeout(() => {
    isSpeaking.value = false
  }, text.length * 200) // 估算时间
}

async function sendMessage() {
  const text = userInput.value.trim()
  if (!text) return

  messages.value.push({
    id: Date.now(),
    role: 'user',
    content: text
  })

  userInput.value = ''

  // 发送用户回答，获取AI追问
  const aiResponse = await fetchAIResponse(text)
  handleAIMessage(aiResponse)
}

async function generateTTS(text) {
  // 替换为你的TTS API调用
  const response = await fetch('/api/tts', {
    method: 'POST',
    body: JSON.stringify({ text })
  })
  const blob = await response.blob()
  return URL.createObjectURL(blob)
}

async function fetchAIResponse(text) {
  // 替换为你的AI API调用
  const response = await fetch('/api/interview/message', {
    method: 'POST',
    body: JSON.stringify({ message: text })
  })
  const data = await response.json()
  return data.reply
}
</script>
```

## 🔧 故障排除

### 模型不显示

1. 检查浏览器控制台是否有错误
2. 确认 `public/live2d/` 目录结构正确
3. 确认 `chitose.model3.json` 文件存在

### 动画不流畅

1. 关闭其他占用GPU的程序
2. 在浏览器设置中启用硬件加速

### 跨域问题

如果前后端分离，确保：
- 前端开发服务器代理了 `/api` 请求
- 或后端设置了正确的 CORS 头
